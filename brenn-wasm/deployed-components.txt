# WASM component packages shipped to deployments.
#
# One package name per line; blank lines and lines starting with `#` are
# ignored. A package name is what a configuration resolves a component by — the
# `@<name>` its class is imported from — and it is the basename of the package
# directory the build emits, the release stages as `components/<name>/`, and the
# deploy script installs into COMPONENTS_DIR on the target host.
#
# Test-only components (e.g. replay-fault-test) are deliberately omitted — they
# must never ship to a deployment.
#
# When you add a new deployable WASM component: add its `component_package`
# target to COMPONENT_PACKAGES in BUILD.bazel AND add its package name here, or
# it will not be deployed.
